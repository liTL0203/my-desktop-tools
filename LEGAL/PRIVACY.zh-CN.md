# 隐私政策

**最后更新：** 2026-08-16  
**生效日期：** 2026-08-16

> **v1.7.0 变更：** 收集面进一步收缩并简化为**单一开关**——不再收集屏幕分辨率与 CPU 架构；移除每次请求携带的 referrer 固定字段（原为项目仓库链接）；原 L0（核心）与 L1（聚合）两级开关合并为单一的「匿名使用统计」开关。
>
> **v1.6.0 变更：** 收缩收集面——移除 Level 2 细粒度行为层级（Tab 切换、页面停留、侧边栏切换、主题切换不再收集）；移除更新检测事件；插件启停不再上报插件名称（仅插件 ID）；快捷启动点击仅对插件/应用类型上报项目 ID（文件/网址类型不上报项目 ID，避免泄露文件路径）。
>
> **v1.5.0 变更：** 丰富各等级数据字段——L0 新增 CPU 架构和会话时长；L1 新增插件名称、项目 ID、更新检测事件；L2 新增侧边栏切换和主题切换事件。
>
> **v1.4.0 变更：** 所有数据收集级别（含 L0 核心）均改为完全 opt-in。移除 L0 的"强制/不可关闭"描述。用户在设置中主动开启云端分析之前，不会收集任何数据。
>
> **v1.3.0 变更：** 补充说明 pageview 会话初始化事件及每次请求携带的固定元数据字段（url/title/referrer/hostname）。
>
> **v1.2.0 变更：** L0 数据采集新增屏幕分辨率（设备类型统计）。

本隐私政策描述了「桌面工具箱」（以下简称"本应用"）如何收集、使用和保护您的数据。

## 数据收集

云端分析为**单一开关、完全可选（Opt-in，默认关闭）**：在您于「设置 → 隐私」主动开启之前，本应用不会向任何服务器发送任何分析数据。

开启后，将收集以下**匿名使用统计**：

- 应用启动 / 退出事件（退出事件附带会话时长，单位秒）
- **会话初始化事件**（启动时发送一次 pageview，用于在分析仪表盘中建立访客会话；驱动访客总数等聚合数据）
- 应用版本号
- 操作系统类型（Windows / macOS / Linux）
- 界面语言（zh-CN / en-US）
- 插件启动 / 停止事件（仅插件 ID；停止事件附带运行时长秒数，**不含插件名称**）
- 快捷启动点击事件（仅项目类型；插件 / 应用类型附带项目 ID，**文件 / 网址类型不上报项目 ID，不收集文件路径**）
- 匿名设备标识（随机生成的 UUID，不基于硬件指纹）

此外，每次分析请求携带以下**固定元数据**（所有用户共享的常量，不含任何个人或设备特定信息）：

- `url`：虚拟路由标识（如 `app://main`）
- `title`：固定应用名称「My Desktop Tools」
- `hostname`：固定伪主机名 `app.my-desktop-tools.local`

**法律依据：** 用户同意 — 仅在用户主动开启时收集，默认关闭。

> **匿名设备 ID 说明：** 随机一次性生成（不基于硬件指纹）并仅存储在本地，只用于分析仪表盘中的会话分组，无法通过该 ID 逆向识别您的硬件或身份。

> **历史层级说明：** v1.6.0 及更早版本采用 L0 / L1 / L2 三级分级模型。L2 细粒度行为（Tab 切换、页面停留、侧边栏、主题）已于 v1.6.0 移除；v1.7.0 起 L0 与 L1 合并为上述单一列表，并停止收集屏幕分辨率、CPU 架构与 referrer 字段。旧配置中对应的分级开关均已废弃且不再生效。

## 我们不收集的数据

我们明确**不收集**以下信息：

- 您的姓名、邮箱、电话号码或任何个人身份信息（PII）
- 您系统中的文件内容或文件路径
- 剪贴板内容
- 浏览器历史或凭证
- 硬件序列号
- 屏幕分辨率、CPU 型号 / 架构等硬件规格

## IP 地址与网络数据

本应用**不会主动采集、传输或存储**您的 IP 地址。发送到分析服务器的任何数据中均不包含 IP 字段。

然而，作为所有 HTTPS 通信的固有特性，自托管的分析服务器（Umami）在网络层会接收到您的来源 IP 地址。这是标准 HTTP 行为，在任何客户端-服务器架构中都无法避免。

**服务器如何使用您的 IP：**

- 聚合地理统计（仅国家级别/地区级别，在仪表盘中显示为「访客国家分布」）
- 机器人检测和垃圾防护（通过 `isbot` 库）
- 会话去重（相同 IP + 相同浏览器 = 同一访客会话）

**您的 IP 如何受到保护：**

- 原始 IP 地址**不会**在分析仪表盘中展示，也不会作为个人标识存储
- IP **不会**与您的匿名设备 ID 以任何可查询的形式关联
- IP **不会**共享给任何第三方服务
- IP **不会**用于个人用户追踪、画像或跨站识别
- 服务端访问日志（如有）仅保留不超过 7 天，仅供安全审计用途

## 数据存储

### 本地存储

本地使用统计（运行时长、打开次数）存储在本地 SQLite 数据库中：

- Windows：`%APPDATA%/my-desktop-tools/stats/stats.db`

此数据永远不会离开您的设备。

### 云端存储

启用云端分析后，数据通过 HTTPS 发送到开发者自托管的 Umami 分析实例。不使用任何第三方分析服务（如 Google Analytics、Mixpanel 等）。

**数据保留：** 云端分析数据保留 90 天，之后自动聚合清理。

## 您的权利

- **访问权：** 您可以查看应用收集了哪些类型的数据（见上方数据收集分级；设置 → 隐私 页提供"收什么/发到哪/怎么管"透明度说明卡）
- **删除权（本地）：** 您可以随时通过「设置 → 隐私 → 删除我的数据」清空本地待上报队列并关闭上报。注意：该操作**不会删除云端已上报的数据**（分析服务无单条删除接口），云端数据将在保留 90 天后自动过期清理
- **撤回权：** 您可以随时通过「设置 → 隐私」关闭云端分析开关
- **退出权：** 所有可选数据收集均为 opt-in（默认关闭），您无需做任何操作即可保持完全离线

## 安全措施

- 所有网络传输使用 HTTPS 加密
- 分析数据不包含可追溯到您的个人标识
- 匿名设备 ID 为随机生成的 UUID，不基于硬件指纹
- 分析服务器由开发者自建和管理
