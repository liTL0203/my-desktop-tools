# AI 翻译

选中文字后一键 AI 翻译，支持自动识别源语言和多目标语言切换。

## 功能介绍

- **一键翻译**：在任意应用中选中文字，通过鼠标中键触发快捷操作面板，选择「AI 翻译」即可
- **多目标语言**：支持中文、英文、日语、韩语等目标语言切换
- **AI 驱动**：调用核心程序配置的 AI 服务（DeepSeek、OpenAI、Claude、Ollama 等），无需自建模型
- **轻量高效**：翻译结果在独立弹窗中展示，支持一键复制

## 使用说明

1. 在核心程序「AI 服务」页面配置至少一个 AI Provider（如 DeepSeek、OpenAI 等）
2. 在任意应用中选中需要翻译的文字
3. 按下鼠标中键（或自定义快捷键）唤起快捷操作面板
4. 选择「AI 翻译」
5. 翻译结果自动展示在弹窗中，可切换目标语言或一键复制

## 注意事项

- 使用前需在核心程序设置中配置 AI 服务 Provider 和 API Key
- 翻译功能依赖网络连接（本地 Ollama 除外）
- API Key 使用 AES-256-GCM 加密存储，不会上传到任何服务器
