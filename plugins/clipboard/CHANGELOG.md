# Changelog

本文件记录剪切板历史插件的版本变更。
版本号以 manifest.json 为唯一来源，由 build-zip.mjs 自动同步到 package.json 与本文件。

## [1.1.0] - 2026-09-23

### 新增

- 图片条目：截图/图片复制自动记录（CF_DIB 优先、CF_BITMAP 经 GetDIBits 归一降级），
  列表缩略图 + 详情预览 + 一键写回剪贴板（原始画质）；PNG 缩略图经 extra 传输，
  原始 DIB 落 images 表随环形淘汰回收；单图上限 16MB

- 设置页布局优化：单列 560px 靠左改为响应式网格（宽窗双列、数据卡横跨底部、
  窄窗自动单列），消除右侧大片空白；数据卡新增"清空未置顶"入口
- 二维码随条目切换自动收起（修复：切到其他内容后二维码滞留显示）
- 二维码与图片条目"另存为"：导出 PNG 到 plugin-data/clipboard/exports/
  （图片为原始画质），保存后自动打开所在目录
- 默认随核心自启（on_startup，事件驱动零空闲 CPU；可在插件管理-资源监控关闭）
- 空态提示展示 Alt+V 呼出快捷键；插件管理页插件名旁展示热键徽标（随核心更新）
- 全局热键 Alt+V 误触 Quick Launcher：核心全局 handler 按快捷键身份过滤
  （随核心更新生效，见 core INDEX A11）

## [0.1.0] - 2026-09-21

### 新增

- 剪切板自动监听与记录（clipboard-win 事件驱动，空闲零 CPU）
- 智能类型识别：文本 / 链接 / 颜色 / 文件 / 代码 / JSON
- 敏感内容识别与掩码（验证码 / 银行卡号 Luhn），详情可临时回显 60 秒
- 来源进程记录与黑名单（默认排除远程桌面 mstsc.exe）
- SQLite 持久化存储（plugin-data/clipboard/），环形容量 100–2000 条可调，重复去重
- 搜索（关键词 / 来源应用）、类型筛选、置顶收藏永不淘汰
- 一键复制回贴（自回环抑制，不自我记录）
- 详情面板二级操作：链接打开与二维码、JSON 格式化压缩、颜色 HEX/RGB 互转、文件打开所在目录
- 多选合并复制（按勾选顺序）
- 双主题（跟随核心）、中英双语
- 全局热键 Alt+V 快捷呼出（核心插件热键通道，manifest hotkey 字段，按下 toggle 独立窗口）
