# 剪切板历史 clipboard v1.1.0

中文正文在前，英文详情折叠。

让复制过的内容能被搜索、被加工、被保护：自动监听并智能分类记录剪切板历史，验证码与卡号自动掩码保护，置顶收藏当短语模板，链接生二维码、JSON 一键格式化、颜色 HEX/RGB 互转等就地加工能力，还支持多选按顺序合并复制。事件驱动监听空闲零 CPU，SQLite 持久化重启不丢。支持 Alt+V 全局热键一键呼出/隐藏。本版新增图片记录：截图与图片复制自动入史，列表缩略图预览、详情查看、原始画质一键写回；设置页改为响应式多列布局。

<summary>English</summary>

Clipboard history that makes copied content searchable, processable and protected: automatic recording with smart type detection, sensitive masking for OTP and card numbers, pin-as-template, per-type actions like QR code and JSON formatting, plus multi-select merge paste. Event-driven listener with zero idle CPU, SQLite persistence across restarts, an Alt+V global hotkey for instant show/hide, image recording with thumbnails and full-quality copy-back, and a responsive multi-column settings layout.
