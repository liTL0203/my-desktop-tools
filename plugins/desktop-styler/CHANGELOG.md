# 0.1.0 更新说明 (2026-09-17)

## 新增
- 首版：AI 驱动的桌面美化插件（desktop-styler）
- 桌面元素三件套：Dock 启动栏（三向停靠/悬停放大/毛玻璃）、顶部菜单栏、时钟小组件（覆盖窗口，随开随关）
- 系统设置白名单四项：壁纸（内置渐变预设 + 原壁纸还原）、系统深浅色、任务栏对齐（Win11）、任务栏自动隐藏——改前自动快照
- 方案体系：内置 mac 深色 / 极简工作 / 系统默认 + 自定义方案保存/删除
- 一键还原：桌面元素 + 系统设置（按快照）+ 全部参数；还原不依赖插件前端（AI 通道同样生效）
- AI 技能组 7 项（get_capabilities / get_state / set_params / list_profiles / apply_profile / save_profile / restore_default），结构化参数 + 范围校验 + 审批
- 五页主面板 + 迷你桌面实时预览（参数即时映射）
- 核心前置：插件覆盖窗口机制（manifest overlays）+ desktop 技能桥（白名单制转发）
