# v1.3.0 更新说明 (2026-10-06)

## 新增

- **中文词级修复**：启用 unicode 分词，中文逐字、西文按词高亮（此前中文整句一个 token，词级失效）
- **差异概览标尺**：视图右侧差异分布竖轨，点击跳转对应位置
- **虚拟滚动**：扁平行模型 + 固定行高窗口渲染，数万行输入不再卡顿
- **回到第一处**：差异清单导航新增首差异按钮
- **高级忽略规则**：正则规则（如 `^\s*//` 注释行、`updatedAt: .*` 时间戳字段）增删启停，实时重算
- **数值容差**：0–5% 阈值内的数值差异视为相同（有效数字量化）
- **CSV 表格对比**：按键列对齐（顺序无关），单元格级 旧值→新值，列头变化徽标，仅差异行过滤
- **文件夹对比**：递归对比两目录（快速=大小+mtime / 内容校验=SHA-256），状态过滤+汇总+目录选择器，文本文件点击下钻行级对比（后台 job 不阻塞心跳）
- **图片对比**：并排/滑动/叠加/差异混合四模式，差异像素统计，尺寸不一致自动按左图缩放比较
- **导出 HTML 报告**：自包含单文件（统计徽章+差异清单+明细），本地生成无云端
- **QuickAction 接入**：选中文本 → 预览卡（含剪贴板对比统计）→「与剪贴板对比 / 设为左·右侧」三个动作

## 修复

- 引擎结果形状守卫：异常响应走空态而非渲染错误

# v0.1.0 更新说明 (2026-09-19)

## 新增

- 初始版本
- 文本 / 代码对比：行级 + 词级高亮（similar Myers 引擎，本地计算）
- 三视图：并排 / 统一 / 仅差异；未变更区域自动折叠（≥6 行，上下文 2+2）
- 差异清单：摘录预览、点击跳转定位、上一处 / 下一处巡检
- 忽略规则：行尾空白 / 全部空白 / 大小写，实时重算并联动统计与相似度
- JSON 结构对比：键序无关、数组重排识别（⇄）、类型变化标注、树视图 ⇄ 原文切换、非法 JSON 自动回退
- 输入：粘贴 / 拖拽文本文件（≤10MB）/ 系统文件对话框；交换左右；Ctrl+Enter 对比；实时对比（可关）
- 偏好持久化：视图 / 忽略规则 / 实时开关 / 页签，重启保留
- 明暗双主题与中英双语
