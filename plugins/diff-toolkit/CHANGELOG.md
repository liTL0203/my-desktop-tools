# v0.1.0 更新说明 (2026-09-19)

## 新增

- 初始版本
- 文本 / 代码对比：行级 + 词级高亮（similar Myers 引擎，本地计算）
- 三视图：并排 / 统一 / 仅差异；未变更区域自动折叠（≥6 行，上下文 2+2）
- 差异清单：摘录预览、点击跳转定位、上一处 / 下一处巡检
- 忽略规则：行尾空白 / 全部空白 / 大小写，实时重算并联动统计与相似度
- JSON 结构对比：键序无关、数组重排识别（⇄）、类型变化标注、树视图 ⇄ 原文切换、非法 JSON 自动回退
- 输入：粘贴 / 拖拽文本文件（≤10MB）/ 系统文件对话框；交换左右；Ctrl+Enter 对比；实时对比（可关）
- 偏好持久化：视图 / 忽略规则 / 实时开关 / 页签，重启保留
- 明暗双主题与中英双语
