## [1.2.0] - 2026-08-27

首个完整版本，覆盖 PRD V1.0 → V1.1 → V1.2 三期全部功能。

### V1.0 核心管线
- 导入：点击/拖拽多选导入，256KB 分块上传协议，EXIF Orientation 自动校正
- 队列：胶片栏管理（切换/删除/拖拽排序），上限 100 张
- 画布：棋盘格透明底、滚轮缩放（5%-3200%）、平移、双击复位
- 转换：JPEG/PNG/WebP/BMP/ICO，ICO 多尺寸层
- 压缩：质量滑块（实时体积预估）+ 目标体积二分（JPEG）
- 缩放：百分比/像素双模式 + 预设
- 裁剪：自由 + 8 种比例锁定，8 手柄交互
- 旋转：90°/翻转即点即应用，±45° 校直 + 自动裁边
- 换底色：自动检测/手动取色、边缘泛洪/全局颜色键、容差/羽化
- 批量处理与批量保存（命名冲突自动递增）
- 撤销/重做（Ctrl+Z/Y），保存对话框（rfd 原生）

### V1.1 证件照 + 打码
- 证件照：内置规格表 + 自定义预设持久化，一键出片组合 op
- 六寸排版：1800×1200 @300dpi 自动铺排
- 局部打码：马赛克/高斯模糊多区域

### V1.2 拼接 + 水印 + 隐私
- 长图拼接：纵向/横向、对齐、间距、最窄归一
- 文字水印：ab_glyph 栅格化（微软雅黑候选链），平铺/九宫格
- 图片水印：透明合成、缩放、平铺/九宫格
- EXIF：信息面板查看 + GPS 隐私警示；导出重编码天然清除
- 形状裁剪：圆角矩形/圆形（SDF 抗锯齿）

### 工程
- 77 个 Rust 单元测试（算子/上传状态机/坐标换算/EXIF/排版）
- cargo clippy 零警告；前端 vue-tsc 严格类型
