# v1.3.0 更新说明 (2026-10-08)

## 新增（竞品吸收「擦得更安心」四件套）
- 锁定期防息屏（默认开启）：防护期间屏幕保持常亮，横幅与倒计时始终可见
- 拦截音效（可选，默认关）：拦截到输入时轻响一声（内嵌资源、150ms 节流），擦拭时不抬头也能确认防护在工作
- 放行媒体键（可选，默认关）：防护期间音量/播放暂停等媒体键仍可使用
- 解锁短语（可选第 4 手势）：键入自定义短语（3-8 位小写字母/数字，默认 unlock）解锁，刻意性最强；须连续键入，非字母数字键打断重输

# 1.0.0 更新说明 (2026-09-25)

## 新增
- 一键防护：锁定全局键盘与鼠标输入（Win32 低级钩子，仅防护期间安装），擦拭误触全部拦下，屏幕保持常显
- 快速开启：主窗口 / 快捷启动关键词直达；可选「开窗即锁」3 秒倒计时直达
- 专属手势解锁：默认 2 秒内连按 `Esc ×3`；可切换长按 Esc 3 秒 / Ctrl+Alt+U
- 多重自动恢复兜底：硬性时长到点强制解除（默认 30 分钟，5-120 可调不可关闭）+ 插件异常退出系统级输入自愈
- 顶部锁定横幅：剩余时间 / 已拦截次数 / 解锁方式提示 / 手势进度（圆点与长按进度条）
- 锁定范围：全部 / 仅键盘 / 仅鼠标；设置本地持久化（plugin-data/input-lock/）
- 明暗双主题 + 中英双语
