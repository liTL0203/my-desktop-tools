# 更新日志

## 0.1.0（2026-09-26）

首个开发版本。

- 附近设备自动发现（UDP announce/probe）与手动地址添加
- 六位码配对（双方公钥 ECDH 派生，码一致=无中间人）与信任设备管理
- 文件/文件夹直传（4MB 分块 + 偏移协商 + 落盘 journal），断点续传跨重启有效
- 远程浏览共享目录与多选拉取（只读、路径穿越防护）
- 浏览器收发端（sidecar 内嵌页 + 配对码授权，手机零安装互传）
- 信任设备剪贴板同步（文本/链接，敏感内容自动掩码不外发）
- 点对点加密（X25519 ECDH + ChaCha20-Poly1305，正文全密文）
- 传输管理（进度/速度/暂停/取消/历史/统计）与网络诊断

### 修复（验收第一轮，2026-09-26）

- 修复浏览器页点「下载」报 unauthorized：页面卸载时发送的 bye 注销请求与下载请求竞态误杀会话——移除 bye（会话按 2 小时无活动自动过期）
- 浏览器配对状态持久化：token 存浏览器本地，刷新免重输配对码
- 「发送文字」支持浏览器设备：网页新增「对方发来的文字」区（一键复制）
- 网络诊断防火墙建议升级：精确补救步骤 + 可复制的放行命令（含重新触发系统弹窗的方法）
- 浏览器配对码支持固定：设置中可填六位数字固定码（留空随机），固定模式「换一个码」自动隐藏
- 浏览器页全新视觉：渐变头部/卡片式文件行/进度百分比/聊天式双向文字（可回复到电脑，Enter 发送）/自动增高输入框；修视口不足时居中布局裁切（margin:auto）
- 新增浏览器回信端点 POST /api/webep/text（token 授权 → 电脑历史与弹提示）
- **Linux 守护节点（lan-share-noded）**：musl 静态二进制 + toml 配置 + systemd 单元 + /admin 管理页；与 Windows 同协议（发现/配对/加密直传/续传/共享目录）；产物 publish/linux-x86_64/lan-share-linux.tar.gz
- **命令行互传指引**：无浏览器的 Linux 服务器可用 curl 完成配对/发文字/上传/下载（RELEASE 附完整命令）
- **完整时间戳**：两端聊天每条消息显示「年-月-日 时:分:秒」，日期分组条带年份与星期（今天 · 2026-09-27 周日）
- **会话显示主机网络信息**：每台设备向对端广播自身网卡 IP↔MAC 表（GetAdaptersInfo），会话列表与聊天头部显示「IP · MAC」（浏览器设备显示 IP）
- **浏览器收发常驻横幅**：聊天页顶部一眼可见——小二维码（点击放大）+ 访问地址与大号配对码均点击即复制 + 一键换码/开关
- **设备页并入聊天页**：四页签（聊天/远程浏览/剪贴板/设置）；会话侧栏整合设备发现（未配对设备一键配对条目）、手动添加、浏览器收发弹窗（二维码/配对码/开关）、进入自动扫描；聊天头部直达「浏览文件」
- **接收文件「打开所在文件夹」**：电脑端聊天内接收文件卡新增可见按钮，定位到文件所在目录（多文件直达保存目录）
- **浏览器页统一聊天重设计**：文字/收文件/发文件并入同一时间线（出向文件卡带实时上传进度与"已送达"，入向带下载按钮）；+ 按钮选文件与整卡拖放上传（拖放遮罩提示）；时间显示精确到秒；消息顺序修正为旧上新下并按天分组
- **聊天式会话重设计**：五页签（聊天/设备/远程浏览/剪贴板/设置）；微信式会话时间线统一承载文字、文件收发与实时传输进度（发送/接收/传输三页合并）；会话按最近活动排序、支持日期分隔与断线续传徽标；文件可拖入会话直接发送
- 浏览器设备命名：网页可给自己起名（配对自带/可改/刷新重报），电脑端设备列表与传输历史按名区分多台浏览器
- 插件端界面精修：应用徽标与激活页签强调色、设备卡渐变头像与悬停浮起、发送页图标圈拖放区与文件类型配色、传输统计四色顶条与渐变进度
