# Changelog

## 0.1.0 (2026-09-30)

首个开发版（待真机验收）。

### 新增

- 合盖/开盖电源事件检测（`PowerSettingRegisterNotification`，注册回显自动跳过）
- BitBlt 冻结帧管线（Per-Monitor DPI、JPEG q85、≤768KB 分块、60s TTL 清扫）
- 全屏透明覆盖层播放（overlays 常驻 + planEpoch 拓扑变化自动 sync）
- 七个转场效果全量移植自交互 Demo：凝霜入眠 / 星尘归仓 / 复古关机 / 伙伴入眠 / 破晓展开 / 涟漪苏醒 / 伙伴迎接
- 合盖策略接管：AC/DC 原值备份、一键还原、启动自愈核对、外部改写检测
- 延时入睡兜底（1-30 分钟可调）+ 仅接电源时接管
- 设置页：状态卡 / 行为开关 / 效果选择 / 手动预览 / 事件日志（中英双语、明暗主题）
- 台式机 unsupported 自动降级
- 覆盖层计划契约修正（`overlays` 键包裹）与播放结束自动清屏（修复预览后黑幕残留盖屏）
- 覆盖与抓屏范围升级为主屏全幅（含任务栏）——收拢终点落在物理铰链位置
- 分类定稿 `system-tools`（visual 不在核心侧边栏渲染清单内，装后不可见——screenshot-tool 同坑修正）
