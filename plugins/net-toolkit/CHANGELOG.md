# v1.2.0 更新说明 (2026-10-08)

## 新增
- **IP 离线库解析**：支持添加 .xdb（ip2region）与 .mmdb（GeoLite2）格式 IP 数据库，本地解析归属地——无需联网查询
- **离线库管理界面**：数据库文件添加、状态显示、查询与结果展示
- **geo 查询离线优先**：可配置开关，离线库命中时不发在线请求

## 0.1.0（2026-09-29 修订）

- 布局重制：侧边栏导航九视图（Ping / 路由追踪 / 端口扫描 / DNS 查询 / Whois / 总览 / 局域网 / HTTP·证书 / IP 计算）

- 新增 Whois：真实 TCP 43 查询，IANA 根 → 注册局/注册商自动跟随，关键字段中文化摘要 + 原始记录
- 延迟图表升级 ECharts（按需引入，面积渐变/均值线/阈值线/悬停提示）
- ARP 读取子进程不再闪控制台窗口（CREATE_NO_WINDOW）

## 0.1.0（2026-09-28）

- 首个开发版本：七页签工作台（总览 / Ping / 端口扫描 / DNS / IP 计算 / 局域网 / HTTP·证书）
- 本机真实探测：ICMP Ping 多目标并排（winping，免管理员）、TCP 端口扫描（开放/关闭/过滤）、自定义 DNS 服务器多台对比
- 离线计算器：子网计算、IPv4/IPv6 进制转换、VLSM 子网规划、MAC 厂商识别（OUI 离线库）
- 局域网：Wake-on-LAN 设备唤醒（魔术包 ×3）、ARP 邻居表（自动标注厂商）
- HTTP·证书：五段耗时瀑布、重定向链、响应头、SSL 证书信息与剩余天数
- QuickAction：选中文本含 IP / 域名 / URL 时右键直达对应探测页签
- 全功能 HelpTip 悬停气泡说明；明暗双主题
