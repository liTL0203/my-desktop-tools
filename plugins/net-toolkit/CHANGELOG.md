# v1.4.0 更新说明 (2026-11-02)

## 新增
- **本机连接（谁在连我）**：局域网新卡展示本机全部 TCP/UDP 连接与监听端口，含所属进程名——哪个程序在联网、谁连着我一眼可查；支持「全部 / 已建立 / 监听」筛选
- 局域网扫描结果支持**一键加入唤醒列表**（扫到设备无需手抄 MAC）
- 总览工具导航补全至 9 卡（新增路由追踪 / 公网判定 / Whois 直达）
- Whois 原始记录一键复制
- **DNS 污染检测**：DNS 页新卡，本地各 DNS 服务器的明文 UDP53 解析结果与 DoH 加密可信通道（阿里→Google）对比；诚实判定口径——仅命中污染特征签名（历史注入 IP / 异常网段应答）或解析器与自身加密通道不一致时判「疑似污染」，境内分歧与境外视角差异如实展示不冒充结论；容忍 CDN 就近调度
- **路由地理轨迹**：路由追踪页新卡，公网跳点按经纬度绘制零资产 SVG 轨迹图（经纬网 30° 步进 + 跳点连线，等距圆柱投影）；坐标来自 GeoLite2-City 离线库或在线归属接口，无坐标时优雅降级为挂库引导

## 优化
- Ping 配置区收纳为分组面板（模式/间隔/包大小/预设同面板，与端口扫描页统一）；实时回包不再每行重复显示同一 IP；告警时间线加状态色左缘
- 路由追踪每跳状态升级为徽章，归属地以标签样式与 IP 分隔；标题行降密
- 端口扫描统计行徽章化，进度条完成后变绿
- 侧边栏总览独立置顶分组
- 离线库 IP 查询输入防抖 300ms（原先每敲一个字符请求一次），回车立即查询
- 双语清扫约 20 处漏网硬编码文案（HTTP 瀑布图例/图表悬浮/Whois 字段表等，英文态不再混出中文）

## 优化
- Sidecar 结构治理：rpc.rs 779 行按域拆分为分发层 + rpc_dns/rpc_sessions（新增 DNS 域命令进 rpc_dns），规避千行硬门槛
- 冗余清理：移除零引用的旧图表样式/类型定义/工具函数与遗留迁移脚本（SidecarResult、fmt_time、.latency-chart、.pbar、patch_ipdb_fe.py），离线库状态类型转正复用

## 修复
- **IP 分类器手动输入框修复**：公网判定页分类器输入框自首发起即丢失（悬空绑定渲染为裸文本），现恢复可输入即判——并新增 mock 驱动自检断言防回归
- 侧边栏版本徽标不再硬编码，构建期从 manifest 注入（此前一直显示 v1.0.0）
- NAT 链路图样式类与 HTTP 重定向链撞名导致的换行布局冲突
- 总览「最近探测」重跑：路由追踪 / Whois 历史不再误跳到 Ping 页
- 清理从未生效的 watchCerts 幽灵设置字段（两端类型同步删除）
- **注册局限流自动退避**：同一后缀被限流后 10 分钟内自动跳过注册局直连、直接走 RDAP 通道——不再每次查询都撞限流墙续期窗口；跳超时下限不再越过剩余预算（三跳叠加越限的根因修复）
- **同步查询超时修复**：核心对插件单次调用为 5 秒硬上限（此前按约 10 秒设计预算），限流兜底链最坏耗时越过上限导致「插件响应超时 (5s)」——Whois / 证书 / 公网出口 / DNS 多类型 / 归属批量全部收敛到 4.5 秒总预算内
- **Whois 限流识别与 RDAP 兜底**：新顶级域（如 .online，Identity Digital 系）注册局限流较严，超限时的英文提示原先被当作查询结果裸显——现识别限流并给出中文说明（含等待建议），并自动尝试 RDAP 通道兜底（HTTPS，限流宽松；结果合成标准字段展示）；.online 加入注册局直连表省一跳
- **公网出口探测改多端点降级链**：原先单点依赖境外 ipify，部分网络直连失败即报「无法访问公网探测服务」——现按 ip-api 自查 → Cloudflare → ipip.net → ipify 顺序降级（任一可达即判定成功），并在明细中显示本次胜出的探测源
