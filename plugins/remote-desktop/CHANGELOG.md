# v0.1.0 更新说明 (2026-09-14)

## 新增
- 内网设备自动发现（UDP 广播，仅同网段）与手动 IP / IP:端口 / 主机名直连（跨网段路由互通可用）
- 一键远程连接（RustDesk 引擎承载画面/键鼠，双向剪贴板与文件传输由引擎提供）
- 无人值守访问：被控服务安装（UAC 一次性授权）、固定密码 / 每次询问 / 白名单三种模式
- 画质预设（自适应/流畅/高清/原始，连接前写入引擎配置）
- RDP 直通通道（被控端为 Windows 专业版时可用；会锁定对方桌面）
- 多会话管理与断开、连接历史与收藏、引擎按需下载/本地导入（SHA-256 TOFU 校验）
- 安全底线：仅允许内网地址连接（代码层锁定，不可关闭）；插件不保存任何访问密码

## 已知限制
- 被控端暂无"谁在连我"实时接入列表（引擎未提供查询接口）
- RustDesk 单实例模式下断开为关闭全部引擎窗口
- 界面文案暂仅中文（i18n 预留）
