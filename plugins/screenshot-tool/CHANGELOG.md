# v1.0.0 更新说明 (2026-09-26)

## 新增
- 初始版本：区域截图（8 柄微调 / 方向键挪动 / 3 倍放大镜取色）
- 标注六件套：矩形 / 椭圆 / 箭头 / 画笔 / 马赛克 / 文字（拖拽实时预览），颜色与粗细可调，撤销重做
- 提取文字：Windows 系统 OCR 离线识别，分块勾选、智能合并、一键复制
- 翻译：复用主程序 AI 网关零配置，对照分栏 / 原位贴回两种形态，可复制译文或双语
- 复制到剪贴板（位图）/ 另存为 PNG·JPG
- 热键 Ctrl+Alt+A **直达截图**（需配套新版主程序：`hotkeyDispatch` 通用分发机制支持）——按键即冻结画面，全程无插件窗口

# 1.1.0 更新说明 (2026-10-06)

## 新增
- 贴图钉屏：截完一键钉在原位，悬停工具栏支持缩放（25% 档）/不透明度/拖拽移动/关闭，最多 6 张常驻（需配套新版主程序的覆盖窗定位能力）
- 历史记录 + OCR 全文搜索：复制/保存/贴图自动归档，按截图里的文字搜索，支持预览/重新复制/删除/清空，可设保留策略
- 窗口智能吸附：框选时悬停自动高亮整窗，点击即选
- 标注增强：序号标签①②③（点击自动递增）、高亮笔刷；绘制中滚轮调节粗细；工具栏右键快速换色；双击选区重复上次动作
- 延时截图：立即 / 1-5 秒可选（对热键直达同样生效）
- 截图问答：对识别文字一键问 AI（解释内容 / 解释报错 / 总结要点 / 自由提问）
- 翻译与识别质量：术语标准译法与识别纠错增强；小字区域自动放大识别
