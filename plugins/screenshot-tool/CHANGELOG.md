# v1.0.0 更新说明 (2026-09-26)

## 新增
- 初始版本：区域截图（8 柄微调 / 方向键挪动 / 3 倍放大镜取色）
- 标注六件套：矩形 / 椭圆 / 箭头 / 画笔 / 马赛克 / 文字（拖拽实时预览），颜色与粗细可调，撤销重做
- 提取文字：Windows 系统 OCR 离线识别，分块勾选、智能合并、一键复制
- 翻译：复用主程序 AI 网关零配置，对照分栏 / 原位贴回两种形态，可复制译文或双语
- 复制到剪贴板（位图）/ 另存为 PNG·JPG
- 热键 Ctrl+Alt+A **直达截图**（需配套新版主程序：`hotkeyDispatch` 通用分发机制支持）——按键即冻结画面，全程无插件窗口
