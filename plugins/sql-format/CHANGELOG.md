# 0.1.0 更新说明 (2026-09-14)

## 新增
- SQL 格式化：五方言（MySQL/PostgreSQL/SQLite/T-SQL/PL-SQL），关键字大小写/缩进/AND·OR 换行/运算符紧凑/语句间空行可配，默认/紧凑/宽松三预设
- SQL 压缩：去注释去空白单行化，字符串字面量保护
- 语法校验：括号/引号配对检查，错误定位到行，状态栏徽标联动
- 多语句拆分与导航：语句 chips + 类型统计，点击跳转结果定位
- CodeMirror 6 双编辑器（输入可编辑/结果只读），lang-sql 语法高亮与补全，亮暗双主题
- 转换工具：SELECT→COUNT、DDL→TypeScript 接口、INSERT→CSV/JSON
- 静态分析：涉及表/字段提取、语句统计、慢查询模式提示
- 片段库：内置 4 个常用模板 + 用户自定义片段（持久化）
- 格式化历史：最近 20 条，点击恢复（持久化）
- .sql 文件打开/保存（sidecar 原生对话框，≤10MB）
- QuickAction 全链路：sql 类型命中（LV1）+ 关键词形状冷筛（LV2）+ --probe 语句统计预览卡（LV3）+ 独立窗口自动载入格式化
- 设置/片段/历史全部本地持久化（原子写 + 损坏 .bak 回退）
- 双语 i18n（zh-CN/en-US）+ 亮暗主题跟随 Core
