# v1.0.0 更新说明 (2026-10-19)

## 首个公开发布版本

桌面性能速览插件：一眼看清电脑现在有多忙、是谁在忙。

- **悬浮性能条**：窗即条设计（对标 TrafficMonitor），CPU / 内存 / 网速 / GPU 实时展示，数值按负载着色
- **双击看归因**：双击悬浮条打开面板，查看是哪些进程在占用资源，含每核负载柱图与 CPU 实时频率
- **真右键菜单**：右键弹出 WinUI 风上下文菜单，子项钻入式分页（显示项目 / 形态 / 网速单位 / 负载着色 / 锁定位置 / 全屏隐藏 / 关闭）
- **自由拖动与锁定**：按住拖到任意位置（含多显示器）自动记忆；可锁定防误碰
- **点击穿透**：穿透模式下悬浮条不拦截任何鼠标操作，看视频不挡画面
- **全屏自动隐藏**：前台应用全屏（游戏 / 视频）时自动隐藏让位，退出全屏自动恢复
- **外观自定义**：背景三态（深色玻璃 / 浅色玻璃 / 纯文字透明）+ 字号三档
- **负载告警与回放**：持续高负载防抖提醒不误报，负载账本可回放
- **轻量无依赖**：免管理员、免驱动、免装第三方运行库

# v0.2.0 更新说明 (2026-10-07)

## 新增
- **悬浮条整体重设计**（对标 TrafficMonitor / WinStats）：窗即条——窗口尺寸=条尺寸，去外环留白与大投影，1px 边框平贴桌面；系统字体栈（Segoe UI / 微软雅黑 UI）+ 更大数值；前缀式标签「CPU 23%」替代后缀小字；网速/CPU/内存/GPU 数值按负载着色（>70 警示 / >90 危险）
- **真右键菜单**：右键悬浮条弹出 WinUI 风上下文菜单（打开性能面板 / 显示项目 / 形态 / 网速单位 / 按负载着色 / 锁定位置 / 全屏隐藏 / 关闭），子项钻入式分页，Esc / 失焦 / 15 秒自动关闭
- **双击打开归因面板，单击不再误触**（TrafficMonitor 同款点击语义）
- **点击穿透**：穿透后悬浮条不再拦截任何鼠标事件（看视频不挡画面），从设置页或归因弹层解除
- **全屏时自动隐藏**：前台应用全屏（游戏/视频）时悬浮条隐藏并穿透让位，退出全屏自动恢复（可在菜单关闭）
- **背景三态**：深色玻璃 / 浅色玻璃 / 纯文字透明（适配明暗壁纸）
- **字号三档**：小 / 中 / 大，窗口尺寸随之缩放
- **锁定位置**：锁定后悬浮条不可拖动（防误碰）
- **悬浮条自由拖动**：按住左键拖到任意位置（含多显示器），松手自动记忆，重启/重建窗口回到原位（需配套新版核心的 `move_plugin_overlay_window` 命令；旧核心下自动降级为锚定定位）
- **每核负载柱图**：归因弹层展示每个核心的实时负载柱（按负载着色）
- **CPU 频率**：CPU 卡与归因弹层显示实时平均频率（如 "4.0 GHz"）
- **网速单位设置**：自适应 / 固定 KB/s / Mb/s（码率口径，对标宽带带宽）三档

## 优化
- 设置变更经 `overlay-synced` 事件跨窗口实时跟随（形态/穿透/位置在 HUD 窗口即时生效）
- 悬浮条拖拽帧 rAF 节流，移动平滑不卡顿
- **高 DPI 适配**：悬浮条窗口尺寸按所在显示器缩放比换算（150% 缩放屏不再出现窗口与内容错位的裁切/留白）；位置记忆与拖动均为物理像素口径
- **窗口宽度按显示项计算**：不同项目组合下窗口不空裁不挤压
- **归因弹层防遮挡**：贴近屏幕下缘时自动翻到悬浮条上方显示，位置超界自动钳制回工作区内；锚定模式下弹层相对 HUD 偏移不再盖住悬浮条本体
- **数值防抖**：速率/百分比数字等宽 + 固定槽位（9.9→10.1 不挤动布局）

# v0.1.0 更新说明 (2026-10-01)

## 新增
- 初始版本：悬浮 HUD（胶囊/文字条/卡片三形态，网速/CPU/内存/GPU/磁盘/电池可选项）
- HUD 点击展开归因弹层：三指标速览 + Top 进程（含 TCP/UDP 连接徽标）
- 主面板五页：概览（六卡速览 + 网速双序列主图 10m/30m/1h + Top 进程 + 异常事件）、进程（CPU/内存排序）、流量账本（套餐额度环形 + 80%/95% 超额提醒 + 近 14 天柱状图 + 活跃连接进程）、告警（五内置规则防抖触发 + 历史 + 进程快照回放）、设置
- 实时数据经 sidecar notify 通道每秒推送（plugin:event metrics），前端零常驻轮询
- 采集引擎全程免管理员、无内核驱动：CPU/内存/进程（sysinfo）、GPU 利用率（PDH 英文计数器）、显存（DXGI）、电池（PowerStatus）、磁盘 IO（PDH）、连接归因（IpHelper）
- 流量账本防回绕/重启跳变差值算法 + 本地时区日切 + 周期重置日套餐
