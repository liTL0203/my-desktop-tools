# v1.5.0 更新说明 (2026-11-02)

## 新增
- **校验错误列表（点击定位）**：输入面板头部错误徽标展开下拉列表，逐条显示 行:列 + 原因，点击任意条即定位到对应输入行——此前多错误只能跳第一条；「校验」按钮与 QA「校验定位」入口在有错时自动展开列表
- **转换结果保存为文件**：转换面板输出区新增「保存」，按方向直接落盘 .json / .xml / .csv（CSV 可直接用 Excel 打开，不必再复制粘贴手建文件）

## 修复
- **XML → CSV 记录自身文本丢失**：记录集模式只取属性列与子元素列，`<item>甲</item>` 这类纯文本记录会输出空表、`<item id="1">文本</item>` 静默丢文本——现在记录带文本时追加 `#text` 列（与 XML→JSON 的 `#text` 键同约定）
- **⚙「JSON 根名」输入框显示默认值而非已保存值**：设置异步加载晚于界面挂载，输入框停留在 `root`；转换实际用的是已保存值，但一编辑就会覆盖——现在跟随设置刷新
- **清空后 XPath 查询基准残留**：清空输入未失效「最近一次格式化」缓存，粘贴新内容后未格式化直接查 XPath 会命中旧文档行号且定位落空——清空现在同时失效该缓存
- **未格式化时 XPath 定位落空**：从未格式化就查询（以原始输入为基准）时，命中点击会试图跳转空的结果编辑器——现改跳输入编辑器对应行

## 优化
- 弹层交互补齐：⚙ 选项弹层 / ⋯ 菜单 / 错误列表均支持点击外部关闭与 Esc 关闭（此前只能再点按钮本身关闭）
- 窗口内图标统一 lucide 线性 SVG（logo / 转义菜单 / 状态栏 ✓✕ / 错误徽标 / 转换复制），不再使用 emoji 图标
- 英文界面补齐：分栏拖动提示、2MB 超限、转换失败、文件对话框四类错误此前为硬编码中文，现走双语

# v1.3.0 更新说明 (2026-10-05)

## 新增
- **XML → CSV 导出**（竞品对标 A1-1）：自动识别记录集形态输出表格（属性列 + 子元素列，缺失留空），任意 XML 兜底为「路径,值」两列扁平表；RFC 4180 转义 + CRLF 行尾
- **文件编码自动检测转换**（A2）：打开文件时依次检测 UTF-8/UTF-16 BOM、严格 UTF-8、GBK——GBK 报文自动转为 UTF-8 载入，状态栏显示「GBK → UTF-8」（国内医保/银行报文场景）
- **压缩「保留注释」开关**（A1-2）：⚙ 选项中可配置，默认关闭保持传输最小化，配置文件语义场景可开启
- **转换结果回填闭环**（A1-3）：输出框新增「作为输入」（链式转换 XML→JSON→改→JSON→XML）与「发送到编辑器」（转换结果直接进主编辑器格式化）

## 修复
- **分栏拖动不跟鼠标**：旧实现按「容器宽−弹性输出面板」换算百分比，而 flex-basis 实按全宽解析——面板以约 2 倍速冲在鼠标前并撞死 30/70 钳制；且 mousemove 在指针移出文档边界后断流导致拖动冻结。改为 Pointer Events + 指针捕获（跨边界不断流）+ 正确映射（面板右边界精确贴鼠标），拖动期间统一 col-resize 光标并禁用文本选中，触摸拖动可用

## 优化
- XML→JSON / XML→CSV 前置结构校验守卫：破损文档拒绝转换并提示先修复，不再静默产出垃圾数据

## [1.0.0] - 2026-09-16

### Added

- **XML 格式化**：缩进 2/4/Tab，保留注释/CDATA/声明/PI，纯文本叶子节点单行，属性换行策略（same/wrap/auto）
- **压缩/最小化**：单行化，去注释，文本内容与 CDATA 保护
- **结构校验**：标签配对多错误扫描 + 严格解析兜底，错误定位到行:列（≤8 条）
- **结构树浏览**：折叠/展开，点击节点定位结果行；节点统计（元素/属性/深度/体积/CDATA/注释）
- **XML ⇄ JSON 双向转换**：属性 `-` 前缀、重复子元素合数组、`#text` 混合、键序保持、根名可配
- **XPath 1.0 查询**：全量 1.0 语法（sxd-xpath），预置表达式，结果节点点击定位
- **实体转义/反转义**：五预定义实体 + 数值实体互转
- **.xml 文件打开/保存**：sidecar 子线程原生对话框
- **多开窗口**：allowMultiple=true，可同时打开多个独立窗口；QuickAction 连续触发各开新窗并各自载入选区（FIFO 队列）
- **QuickAction 集成**：xml 类型 + 形状规则精筛（LV2）、闪探结构结论卡/校验卡（LV3）、动态右键 5 条直达
- 双主题（CSS 变量）+ 中英双语 i18n
