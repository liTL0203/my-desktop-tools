### 新增

- 格式化/校验：缩进 2/4、行宽、可选键排序；语法错误行列定位 + 上下文摘录

- YAML ⇄ JSON 双向互转（方向一键交换）
- 扁平化：点号键值表 + .env 风格复制

- QuickAction 接入：contextRules 冷筛 + --probe 闪探 + 预览卡（结构统计/错误定位）+ 动态右键菜单（actionId 直达页签）
- 文件打开/保存（子线程原生对话框）；偏好持久化（ui-settings.json 原子写）
- 双主题（亮/暗）+ 中英文界面
