# v1.5.0 更新说明 (2026-11-02)

## 修复
- 多文档输入（含 `---`）在格式化页被判无效、lint / K8s 校验 / 锚点视图静默清空：引擎改用 parseAllDocuments 原生多文档解析，分隔符 / 文档间注释 / `...` 结束符往返保留，块标量内的 `---` 不再被误切
- `<<` 合并键在互转 / 扁平化 / 查询 / K8s 校验中未合并（yaml 1.2 模式默认关闭，JSON 里出现字面量 `"<<"` 键）：解析启用 merge
- 重复键直接弹英文错误卡并阻断整条管线，与「移交规范检查」的承诺相悖：解析改宽松（uniqueKeys=false），由 key-duplicates 规则带行列报告，格式化 / 互转照常进行
- 「压缩」按钮只是重跑排版，引擎 minify 分支从未接通：输出风格改为持久化偏好（块式 / 流式），压缩固定去注释 + 不限行宽，保证每文档一行
- 格式选项（缩进 / 行宽 / 保留注释 / 排序 / 单引号 / 序列缩进）勾选后结果不刷新、偏好不落盘：store 对选项对象为浅监听（实测 0 触发），改 deep 监听并即时重算（不吃输入防抖）
- 多文档页首文档丢失头部注释、起始行偏移；文档标签在 K8s 清单上恒为 apiVersion 行（现优先取顶层 kind）
- 键排序改为码点序（localeCompare 随运行环境区域设置变化，格式化输出必须跨机器一致）
- 检查页「语法规则」按钮实际跳到第 1 行，改为「定位首条」问题；查询结果复制的冗余三元清理

## 新增
- 错误卡中文转译：按 yaml 引擎错误码（缩进不一致 / 引号未闭合 / 流式集合未闭合 / 保留字符 / 无效转义 / 别名附属性 等 17 类）给中文说明，英文原文保留在卡片下方供对照；未定义锚点的别名提前定位到行列（引擎在解析期不报、toJS 才抛）
- 规范检查新增 3 条规则：new-line-at-end-of-file（文件末尾换行）/ empty-lines（连续空行超过 2 行）/ colons（冒号前后间距；冒号后缺空格会使整行变成普通文本——这是 yamllint 没有的「你是不是想写映射」提醒，仅对非序列项的标识符形键触发，排除 URL / 时间值与多行标量内部）
- 检查页「展开锚点」：一键把 `&锚点` / `*别名` / `<<` 合并键解引用为普通 YAML 写回输入（注释不保留，Ctrl+Z 可撤销）
- 快捷键：Ctrl+Enter 格式化 / Ctrl+S 保存文件（此前被劫持为「复制」，违反所有编辑器与格式化工具惯例）/ Ctrl+Shift+C 复制结果；按钮 title 标注组合键

## 改进
- 工具栏：格式化 / 压缩变为输出风格开关态（当前风格为主按钮）；格式选项只在格式化 / 互转页签显示（扁平化 / 多文档 / 查询 / 检查页不消费这些选项）
- 多文档 → JSON 互转输出数组（与 yq 惯例一致）；状态栏顶层键改为各文档合计
- 引擎回归驱动 `frontend/engine-check.mts` 扩至 62 条断言（R1–R8 钉住本轮全部修复，`node --experimental-strip-types engine-check.mts`）

# Changelog

## v1.3.0 (2026-10-08)

### 新增（竞品对标批 A1-A6，全部落地）

- **规范检查**（A1）：yamllint 式精简规则集——truthy 是非值歧义 / 重复键 / 行尾空格 / 行长 120 / 多文档缺 --- 起始 / 疑似密钥键名 / 八进制歧义（源文本判定，含 0777→777 前导零丢失提醒）；状态栏规范徽章点击直达
- **查询提取**（A2）：JSONPath 子集即时求值（$.a.b / [0] / [-1] / [*] / ..递归下降），语法速查折叠面板，逐行/全部复制
- **锚点与合并键视图**（A3）：锚点定义（含顶层键摘要）/ 合并键使用点（引入键并集）/ 引用计数，行点击定位
- **K8s 离线校验**（A4）：22 个高频 kind 规格表——apiVersion 前缀匹配 + 浅层必填字段（metadata.name 允许 generateName 例外）；未收录 kind 降级 info 不误报
- **TOML / properties 互转**（A5）：互转泛化为四格式（yaml/json/toml/props）任意组合，一键换向；smol-toml + 自研 props 编解码
- **错误行内定位**（A6）：错误卡「跳转」/ lint 行点击 → 输入编辑器滚动居中 + 整行高亮（编辑下一次变更自动清除）

### 变更

- 重复键不再阻断 YAML→JSON 转换（移交规范检查报告）
- 格式选项新增：单引号风格（标量 type 转换实现——toString 选项不改既有引号样式）、序列缩进
- QuickAction：预览卡新增「规范 N 项提醒」联动（warn 徽章）；右键菜单新增「规范检查」直达
- 六页签工作台：格式化 / 互转 / 扁平化 / 多文档 / 查询 / 检查
